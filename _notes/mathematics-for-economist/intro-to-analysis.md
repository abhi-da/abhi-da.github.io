

Metric Space: A set X (whose elements are called "points") is a metric space if, for any two points p and q in X, there's a real number d(p, q) — called the distance from p to q — satisfying three rules:

(a) d(p, q) > 0 if p ≠ q, and d(p, p) = 0
(distance is positive between different points, and zero from a point to itself)

(b) d(p, q) = d(q, p)
(distance is symmetric — doesn't matter which point you measure "from")

(c) d(p, q) ≤ d(p, r) + d(r, q), for any point r in X
(this is the "triangle inequality" — going directly from p to q is never longer than going through some detour point r)

Any function d that satisfies these three properties is called a distance function or a metric.
